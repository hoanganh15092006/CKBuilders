
# Week 01 - Environment Setup

## 1. Install OffCKB CLI

```bash
npm install -g @offckb/cli
```

![Install OffCKB CLI](install_offckb_cli.png)

## 2. Start CKB Devnet

```bash
offckb node
```

![CKB Devnet Running](CKB_devnet_running.png)

## 3. Check Accounts

```bash
offckb accounts
```

![OffCKB Accounts](offckb_accounts.png)
